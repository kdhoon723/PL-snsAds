# 공개 저장소 관리 기준

이 저장소는 포트폴리오 공개를 목적으로 하므로, 연구 설명력과 안전성을 함께 유지합니다.

## 공개해도 되는 것

- 직접 작성한 학습/추론/점수화 코드
- 원천 광고를 복원할 수 없는 요약 지표와 그래프
- 합성 샘플 데이터
- 민감정보가 제거된 방법론 문서
- 논문/문헌 기반 설계 설명

## 공개하지 않는 것

- `.env`, API 키, 토큰, 쿠키, 서비스 계정
- 실제 수집 원본 dump와 라벨링 원본
- 팀원 실명, 연락처, 로컬 경로, 작업 메모가 포함된 파일
- 모델 체크포인트, 대용량 run 로그, prediction CSV
- 외부 플랫폼 약관상 재배포가 애매한 원문 데이터

## 개발 시 체크리스트

1. 새 파일을 커밋하기 전 `git status --short`로 범위를 확인합니다.
2. 원천 데이터는 `examples/`가 아니라 로컬 비공개 경로에 둡니다.
3. 공개 샘플은 실제 광고가 아닌 합성 문장으로 만듭니다.
4. README의 경로가 실제 공개 트리와 일치하는지 확인합니다.
5. force-push 전에는 current/history 민감정보 스캔을 다시 수행합니다.
