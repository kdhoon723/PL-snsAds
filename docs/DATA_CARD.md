# Data Card — SNS 광고 소비심리 자극 측정

## 공개 범위

이 공개 저장소에는 원천 수집 데이터와 실제 학습 CSV를 포함하지 않습니다. 대신 다음 자료만 공개합니다.

- 모델링/점수화 코드
- 실험 요약 문서와 공개 가능한 시각화 산출물
- 합성 샘플 CSV: `examples/sample_ads_public.csv`
- 데이터 구성 방식과 비공개 기준 설명

## 비공개로 둔 자료

| 자료 | 비공개 사유 |
|---|---|
| 원본 광고 수집 dump | 플랫폼 정책, 원문 재배포 권리, 계정/수집 메타데이터 혼입 가능성 |
| 라벨링 작업 파일 | 라벨러/작성자 흔적, 검수 메모, 중간 판단 근거 포함 가능성 |
| 통합 학습 데이터셋 | 실제 광고 문구와 라벨이 결합된 연구 데이터 |
| 모델 run 로그·prediction CSV | 원천 텍스트 일부와 실험 환경 정보가 섞일 수 있음 |
| 배포 스크립트·로컬 운영 문서 | 개인 로컬 경로, 터널/서버 운영 방식 노출 가능성 |

## 데이터 스키마

공개 샘플 CSV는 다음 열을 사용합니다.

| 열 | 설명 |
|---|---|
| `id` | 샘플 식별자 |
| `text` | 광고 문구 또는 OCR 텍스트 |
| `사회적_정체성` `희소성` `긴급성` `사회적_증명` `가격비교` `권위_신뢰` `호혜성` | 카테고리 multi-label 값, 0 또는 1 |
| `polarity` | 긍정/중립/부정 |
| `intensity` | 강/보통/약 |
| `note` | 샘플 설명 |

## 공개 저장소 사용 권장 방식

- 포트폴리오 검토자는 README, 점수 공식, 실험 분석 문서, 시각화 자료로 문제 정의와 접근법을 확인합니다.
- 실제 모델 재학습은 비공개 데이터셋과 모델 체크포인트가 필요합니다.
- 새 데이터를 공개하려면 원문 재배포 권리, 개인정보, 플랫폼 약관, 팀원/라벨러 동의를 먼저 검토해야 합니다.
