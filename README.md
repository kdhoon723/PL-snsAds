# SNS 광고 소비심리 자극 측정

SNS 광고 텍스트 또는 이미지 OCR 텍스트에서 **7가지 소비심리 자극 카테고리**를 탐지하고, 각 자극의 방향성·강도·조합 효과를 반영해 **0~100점 자극 강도**를 계산하는 한국어 AI 프로젝트입니다.

> 공개 저장소에는 원천 광고 데이터와 모델 체크포인트를 포함하지 않습니다. 코드, 방법론, 실험 요약, 합성 샘플, 공개 가능한 시각화 자료만 남겨 포트폴리오용으로 정리했습니다.

---

## 핵심 아이디어

```text
입력:  "오늘 자정까지만 무료배송과 30% 쿠폰을 제공합니다."
출력:  긴급성 + 가격비교 + 호혜성 → 자극 점수 산출
```

광고 문구가 어떤 설득 전략을 사용하는지 multi-label로 분류하고, 다음 요소를 합산합니다.

- 카테고리 가중치: 권위·신뢰, 사회적 증명, 사회적 정체성, 호혜성, 희소성, 긴급성, 가격비교
- 모델 확률 또는 라벨 확신도
- 방향성: 긍정/중립/부정
- 강도: 강/보통/약
- 시너지: 2~3개 자극은 상승, 4개 이상 과다 자극은 감점하는 Inverted-U 가정

---

## 7개 카테고리

| 카테고리 | 가중치 | 예시 표현 | 설명 |
|---|---:|---|---|
| 권위·신뢰 | 22.1% | 전문가 검수, 인증, 수상 | 전문성·공신력 기반 설득 |
| 사회적 증명 | 15.9% | 누적 판매, 리뷰, 1위 | 다수의 선택을 근거로 한 설득 |
| 사회적 정체성 | 15.6% | 직장인 필수, 갓생러 추천 | 특정 집단 소속감 자극 |
| 호혜성 | 15.1% | 무료 증정, 쿠폰, 사은품 | 선제적 혜택 제공 |
| 희소성 | 12.6% | 한정 수량, 선착순, 품절 임박 | 수량 제한 기반 자극 |
| 긴급성 | 9.6% | 오늘까지, 자정 마감, D-day | 시간 제한 기반 자극 |
| 가격비교 | 9.1% | 정가 대비, 최저가, 30% 할인 | 가격 이득 강조 |

## 점수 공식

```text
Score = Σ_i (w_i × prob_i × p_i × t_i) × synergy(n) × 100
```

| 항 | 의미 |
|---|---|
| `w_i` | 카테고리별 학술 가중치 |
| `prob_i` | 카테고리 예측 확률 또는 라벨 확신도 |
| `p_i` | 방향성 점수: 긍정 +1.0 / 중립 +0.5 / 부정 -1.0 |
| `t_i` | 강도 점수: 강 1.5 / 보통 1.0 / 약 0.5 |
| `synergy(n)` | 양성 카테고리 수에 따른 조합 보정: 1개 1.0, 2개 1.15, 3개 1.25, 4개 이상 0.90 |

점수 공식 구현은 `모델학습/점수계산_최종.py`와 `모델학습/scoring_v2.py`에 있습니다.

## 데이터 공개 범위

이 프로젝트는 실제 학습 단계에서 약 6천 건 규모의 광고/문장 라벨 데이터를 사용했지만, 공개 저장소에는 해당 원본 CSV를 포함하지 않습니다.

공개하지 않는 자료:

- Meta 광고 등 원본 수집 dump
- 라벨링 원본 엑셀/CSV와 검수 메모
- 통합 학습 데이터셋과 train/val/test split
- 모델 체크포인트, run 로그, prediction CSV
- 로컬 서버/터널 운영 스크립트

대신 구조 확인용 합성 샘플을 제공합니다.

```bash
cat examples/sample_ads_public.csv
```

## 실행 예시

### 점수 공식 데모

모델 체크포인트 없이 실행 가능한 자족 예시입니다.

```bash
python 모델학습/점수계산_최종.py
```

### 모델 학습/추론 코드

학습과 추론 코드는 공개되어 있지만, 실제 실행에는 비공개 데이터셋과 모델 체크포인트가 필요합니다.

```bash
# 학습 데이터가 준비된 경우
python 모델학습/train_v3_multitask.py \
  --run-name cycle_public_test \
  --model klue/roberta-large \
  --max-length 256 \
  --batch 8 \
  --lr 1e-5

# 모델 체크포인트가 준비된 경우
python 모델학습/predict_v3.py --text "오늘만 50% 할인 무료배송"
```

로컬 API 서버 코드는 `모델학습/server.py`에 있으며, 배포 주소나 터널 설정은 공개 저장소에 포함하지 않습니다.

## 실험 요약

- KLUE-RoBERTa 계열 모델을 기반으로 카테고리 multi-label 분류와 방향성/강도 예측을 함께 실험했습니다.
- 핵심 개선은 모델 구조보다 데이터 보강과 라벨 설계에서 크게 나타났습니다.
- 시너지, 방향성, 강도 항을 ablation으로 비교해 최종 점수식을 조정했습니다.
- 강도 라벨은 주관성이 있어 한계로 명시하고, 점수는 자동 의사결정이 아니라 분석 보조 지표로 사용합니다.

## 공개 저장소 관리 원칙

- API 토큰과 수집 자격증명은 `.env`로만 관리하고 커밋하지 않습니다.
- 원천 광고 데이터는 권리·개인정보·플랫폼 약관 검토 전에는 공개하지 않습니다.
- 공개 샘플은 실제 광고가 아닌 합성 문장으로 유지합니다.
- 개인 로컬 경로, 작업 메모, 팀원 실명, 배포 터널 정보는 공개 저장소에서 제외합니다.

자세한 기준은 [`docs/PUBLICATION_GUIDE.md`](docs/PUBLICATION_GUIDE.md)를 참고하세요.
