# SNS 광고 소비심리 자극 측정

SNS 광고 텍스트(또는 이미지의 OCR 텍스트)에서 **7가지 소비심리 자극 카테고리**를 탐지하고, **0~100점 자극 강도**를 정량화하는 한국어 AI 시스템.

🌐 **데모**: <https://localhost:7860>
📊 **모델**: KLUE-RoBERTa-large fine-tuned · 카테고리 F1 **0.83**

---

## 무엇을 하나

```
입력:  "오늘만 50% 할인! 무료배송 ✨"
출력:  긴급성(강) + 가격비교(강) + 호혜성(보통)  →  자극 점수 50.9 / 100
```

광고가 어떤 심리 자극(권위·희소성·긴급성 등)을 쓰는지 탐지하고, 각 자극의 방향성·강도·시너지를 합산해 종합 점수를 냅니다.

## 7개 카테고리 (학술 가중치 순)

| 카테고리 | 가중치 | 정의 | F1 |
|---|---|---|---|
| 권위·신뢰 | 22.1% | 전문가·공인기관 검증 (전문의/인증/수상) | 0.86 |
| 사회적 증명 | 15.9% | 다수의 선택·인기 (1위/누적판매/후기) | 0.84 |
| 사회적 정체성 | 15.6% | 집단 소속감 (갓생러/직장인/~하는 사람) | 0.70 |
| 호혜성 | 15.1% | 선제적 혜택 (무료증정/쿠폰/사은품) | 0.88 |
| 희소성 | 12.6% | 수량 제한 (한정/품절/선착순) | 0.86 |
| 긴급성 | 9.6% | 시간 제한 (오늘까지/마감/D-day) | 0.83 |
| 가격비교 | 9.1% | 가격 이득 (최저가/할인율/정가대비) | 0.83 |

가중치는 메타분석 효과크기(피어슨 r값)를 정규화. 분류 체계는 Singla et al.(2023) AAAI 광고 설득 전략을 한국 SNS에 맞게 7개로 재구성.

## 점수 공식

```
Score = Σ_i (w_i × prob_i × p_i × t_i) × synergy(n) × 100
```

| 항 | 의미 | 값 |
|---|---|---|
| w | 학술 가중치 | 권위 0.221 … 가격 0.091 |
| prob | 모델 확률 | 0~1 (보정 없이 그대로) |
| p | 방향성 | 긍정 +1.0 / 중립 +0.5 / 부정 −1.0 |
| t | 강도 | 강 1.5 / 보통 1.0 / 약 0.5 |
| synergy(n) | 시너지 (Inverted-U) | n=2 ×1.15 / n=3 ×1.25 / n≥4 ×0.90 |

> 신뢰도 보정(ĉ)은 ablation 결과 과보정으로 제거됨 (오차 6.83→5.80). 강도(t)가 점수를 가장 크게 좌우.

## 모델

- **KLUE-RoBERTa-large** 멀티태스크: 카테고리(7, multi-label sigmoid) + 방향성(softmax) + 강도(softmax)
- **배포**: Cycle 50 4-모델 앙상블 (F1 0.830). 단일 cycle41(0.826)로도 거의 동일 — 앙상블 이득 +0.004는 미미
- **핵심 개선은 데이터 보강**: v1 0.778 → v2 0.826 (+0.048). 앙상블·multitask 기여는 작음 (Cycle 52 ablation)
- 이미지 입력: Qwen3-VL-8B OCR (lazy load)

## 사용법

### CLI 추론
```bash
source .venv/bin/activate
python 모델학습/predict_v3.py --text "오늘만 50% 할인 무료배송"
# 빠른 단일 모델: --run cycle41_taskweight_cat
# 배치: --text-file inputs.txt --json
```

### 웹 API
```bash
# 서버 실행
python 모델학습/server.py        # → http://localhost:7860 (외부: localhost:7860)

# 텍스트 분석
curl -X POST https://localhost:7860/api/analyze \
  -H 'Content-Type: application/json' \
  -d '{"text":"오늘만 50% 할인 무료배송","model":"v2"}'

# 이미지 분석 (OCR): POST /api/analyze-image  (multipart: file)
```

### 점수 공식만 보기
```bash
python 모델학습/점수계산_최종.py   # 가중치·시너지·ablation·계산 예시 출력
```

## 한계 (정직 명시)

- **강도 라벨 주관성**: IRR κ=0.487 (광고학 평균). 정체성·증명은 0.2 수준
- **방향성 분포 편중**: SNS 광고 99% 긍정 → 부정·중립 검증 신뢰도 낮음
- **시너지 값 임의성**: Inverted-U 모양만 학술 근거, 1.25/0.90 값은 합리적 추정 (광고 효과 fit 없음)
- **앙상블 이득 미검정**: +0.004는 노이즈 수준, 5-fold CV 미실시
- **LLM 라벨링**: 인간 라벨러 검증 부재, LLM 간 합의(κ)만 측정
- **데이터 출처**: 한국 Meta 광고 위주 (YouTube/TikTok/네이버 미반영)
