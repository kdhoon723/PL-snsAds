벡터화 → 카테고리 확률 → 점수 계산

KLUE-RoBERTa-large에서
카테고리 점수가 나오는 원리

발표에서 “문장을 벡터화한 뒤 점수화했다”고만 말하면 중간 과정이 빠져 보일 수 있습니다. 정확히는 벡터화 다음에 분류 헤드가 카테고리별 확률·방향성·강도를 예측하고, 그 예측값을 점수식에 넣어 최종 소비심리 자극 점수를 계산합니다.

핵심 1KLUE-RoBERTa-large는 문장을 바로 점수화하지 않고, 먼저 문장 벡터를 만듭니다.
핵심 2문장 벡터를 분류 헤드가 읽어서 7개 카테고리 확률을 예측합니다.
핵심 3가중치 Wᵢ는 모델이 학습한 값이 아니라, 예측 이후 점수식에서 곱하는 문헌 기반 값입니다.

1. 전체 흐름

01광고 문구 입력예: 오늘만 50% 할인 무료배송
02토큰화사전학습 토크나이저가 숫자 토큰 ID로 변환
03문장 벡터 생성KLUE-RoBERTa-large가 문맥 정보를 벡터로 표현
04분류 헤드카테고리 확률, 방향성, 강도를 예측
05카테고리 확률sigmoid로 7개 카테고리별 probᵢ 계산
06threshold 판정확률이 기준값을 넘으면 해당 카테고리 탐지
07가중치·계수 적용Wᵢ, pᵢ, tᵢ, S(n)을 적용
08최종 점수소비심리 자극 점수 산출
한 줄 요약: 벡터화된 문장을 바로 점수화한 것이 아니라, 중간에 분류 헤드가 카테고리별 확률과 방향성, 강도를 예측하고 그 결과를 점수식에 넣었습니다.

2. 토큰화와 문장 벡터 생성

광고 문구는 먼저 KLUE-RoBERTa-large의 사전학습 토크나이저를 통해 모델 입력으로 바뀝니다. 여기서 사람이 직접 토큰화 규칙을 만든 것이 아니라, 사전학습 모델이 사용하는 토크나이저를 그대로 사용합니다. 

광고 문구 → input_ids, attention_mask → KLUE-RoBERTa-large

KLUE-RoBERTa-large는 입력 문장 전체의 문맥을 반영한 벡터를 생성합니다. 이 벡터는 광고 문구의 의미를 숫자로 압축한 표현이라고 보면 됩니다.

주의: KLUE-RoBERTa-large가 바로 “긴급성 80점”을 내는 것은 아닙니다. 먼저 문장 벡터를 만들고, 그 벡터를 뒤의 분류 헤드가 사용합니다.

3. 벡터 다음 단계: 분류 헤드

벡터화와 카테고리 점수 사이에 빠져 보였던 부분이 바로 분류 헤드(classifier head)입니다. 코드 구조는 다음과 같습니다. 

self.backbone = AutoModel.from_pretrained(model_name)
self.cat_head = nn.Linear(h, 7)
self.pol_head = nn.Linear(h, 7 * 3)
self.int_head = nn.Linear(h, 7 * 3)
구성 요소역할쉽게 말하면
backboneKLUE-RoBERTa-large광고 문구를 문장 벡터로 표현
cat_head카테고리 분류 헤드7개 설득 전략 포함 확률 예측
pol_head방향성 분류 헤드긍정·중립·부정 방향 예측
int_head강도 분류 헤드강·보통·약 표현 강도 예측

즉, KLUE-RoBERTa-large가 만든 문장 벡터를 세 개의 분류 헤드가 읽어서 각각 다른 예측을 수행합니다.

4. 실제 forward 흐름

실제 모델 내부에서는 아래와 같은 방식으로 문장 벡터에서 예측값을 만듭니다.

out = self.backbone(input_ids=input_ids, attention_mask=attention_mask)
cls = self.dropout(out.last_hidden_state[:, 0])

cat_logits = self.cat_head(cls)       # (B, 7)
pol_logits = self.pol_head(cls)       # (B, 7 × 3)
int_logits = self.int_head(cls)       # (B, 7 × 3)
단계의미
out.last_hidden_state[:, 0]문장 전체를 대표하는 벡터를 사용합니다.
cat_head(cls)7개 카테고리 각각에 대한 원점수 logit을 만듭니다.
pol_head(cls)카테고리별 방향성, 즉 긍정·중립·부정을 예측합니다.
int_head(cls)카테고리별 강도, 즉 강·보통·약을 예측합니다.

5. 카테고리 확률은 어떻게 나오나?

분류 헤드가 만든 cat_logits는 아직 확률이 아닙니다. 여기에 sigmoid를 적용하면 카테고리별 확률 probᵢ가 됩니다. 

cat_logits → sigmoid → 카테고리별 확률 probᵢ

예를 들어 “오늘만 50% 할인 무료배송”이라는 문구는 다음처럼 예측될 수 있습니다.

카테고리예상 확률 예시해석
긴급성0.84“오늘만” 때문에 높게 예측
가격비교0.76“50% 할인” 때문에 높게 예측
호혜성0.69“무료배송” 때문에 탐지 가능
권위·신뢰0.05전문가·기관 표현이 없어 낮음
왜 sigmoid인가? 광고 하나에는 긴급성, 가격비교, 호혜성처럼 여러 전략이 동시에 들어갈 수 있습니다. 그래서 하나만 고르는 softmax가 아니라, 카테고리마다 독립적으로 확률을 내는 sigmoid 기반 멀티라벨 분류를 사용했습니다.

6. threshold로 카테고리 포함 여부 판단

확률이 나왔다고 해서 무조건 카테고리로 확정하는 것은 아닙니다. 각 카테고리별 threshold, 즉 기준값을 넘는지 확인합니다. 

카테고리 확률 probᵢ ≥ 해당 카테고리 threshold → 카테고리 탐지
항목역할
probᵢ모델이 해당 카테고리가 들어있다고 판단한 확률
threshold그 확률을 실제 탐지로 인정할 기준값
threshold 조정검증셋에서 카테고리별 F1이 잘 나오도록 조정

따라서 “확률”과 “탐지 여부”는 구분해야 합니다. 점수 계산에는 확률이 들어가고, 어떤 카테고리를 탐지했다고 표시할지는 threshold를 기준으로 판단합니다.

7. 방향성과 강도도 함께 예측

이 모델은 단순히 카테고리만 예측하지 않고, 방향성과 강도도 함께 예측하는 멀티태스크 구조입니다.

예측 대상출력점수식 반영
카테고리7개 카테고리별 확률probᵢ
방향성긍정 / 중립 / 부정pᵢ = 1.0 / 0.5 / -1.0
표현 강도강 / 보통 / 약tᵢ = 1.5 / 1.0 / 0.5

예를 들어 같은 긴급성 표현이라도 “오늘만 할인”과 “3시간 후 마감”은 압박 정도가 다르므로 강도 예측을 따로 둔 것입니다.

8. 그 다음에 가중치 Wᵢ가 들어감

카테고리 가중치 Wᵢ는 모델이 학습해서 만든 값이 아니라, 점수 계산식에서 사용하는 문헌 기반 초기 가중치입니다. 즉, 모델 예측이 끝난 뒤 아래 식에 들어갑니다.

Score = ( Σ Wᵢ × probᵢ × pᵢ × tᵢ ) × S(n) × 100
기호뜻출처/역할
Wᵢ카테고리별 가중치문헌 기반 초기 설계값
probᵢ모델이 예측한 카테고리 확률분류 헤드 + sigmoid 결과
pᵢ방향성 계수방향성 헤드 예측 결과
tᵢ강도 계수강도 헤드 예측 결과
S(n)동시 탐지 보정탐지된 카테고리 수에 따른 보정
중요: “벡터화 → 가중치”가 아니라, 벡터화 → 분류 헤드 → 확률·방향성·강도 예측 → 가중치 적용 순서입니다.

9. 학습할 때는 무엇을 배우나?

학습 데이터에는 광고 문구와 함께 정답 라벨이 들어갑니다. 모델은 예측값과 정답 라벨을 비교하면서 오차를 줄이는 방향으로 학습됩니다.

학습 대상학습 방식의미
카테고리BCE / focal loss7개 카테고리 포함 여부를 맞히도록 학습
방향성cross entropy loss긍정·중립·부정 중 맞는 방향을 고르도록 학습
강도cross entropy loss강·보통·약 중 맞는 강도를 고르도록 학습

반면 카테고리 가중치 Wᵢ는 이 학습 과정에서 업데이트되는 파라미터가 아닙니다. 모델이 예측한 결과를 점수화할 때 사용하는 외부 설계값입니다.

11. 예상 질문 대응

Q1. KLUE-RoBERTa-large가 직접 카테고리 점수를 계산한 건가요?
아닙니다. KLUE-RoBERTa-large는 문장을 벡터로 표현하는 역할을 하고, 그 뒤에 붙인 분류 헤드가 카테고리별 확률을 예측합니다.
Q2. 벡터화 다음에 바로 가중치를 곱한 건가요?
아닙니다. 벡터화 다음에는 분류 헤드가 있고, 이 분류 헤드가 7개 카테고리 확률, 방향성, 강도를 예측합니다. 그 결과가 나온 뒤 점수 계산식에서 가중치를 곱합니다.
Q3. Wᵢ 가중치도 모델이 학습한 건가요?
아닙니다. Wᵢ는 문헌 기반 초기 설계값입니다. 모델이 학습한 것은 광고 문구에서 카테고리 확률, 방향성, 강도를 예측하는 부분입니다.
Q4. 왜 멀티라벨 분류인가요?
광고 문구 하나에 긴급성, 가격비교, 호혜성처럼 여러 설득 전략이 동시에 들어갈 수 있기 때문입니다. 그래서 하나만 고르는 softmax가 아니라 카테고리별 sigmoid 확률을 사용했습니다.

12. 최종 요약

KLUE-RoBERTa-large가 문장을 벡터화하고, 분류 헤드가 그 벡터를 읽어 카테고리별 확률 방향성 표현 강도 를 예측한 뒤, 그 예측값에 가중치와 보정 계수를 적용해 최종 점수를 계산한 구조입니다.
