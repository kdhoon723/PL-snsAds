8. 추론과 점수 계산

학습이 끝난 모델은 새 광고 문구를 같은 방식으로 토큰화한 뒤, 카테고리별 확률, 방향성, 강도를 예측합니다. 그 다음 아래 계산식으로 최종 점수를 만듭니다.

Score = ( Σ Wᵢ × probᵢ × pᵢ × tᵢ ) × S(n) × 100

9. 예시 문구로 점수 계산 이해하기

예시: “오늘만 50% 할인! 무료배송”

  • 오늘만 → 시간 제한이 명확하므로 긴급성
  • 50% 할인 → 할인 폭이 구체적이므로 가격비교
  • 무료배송 → 소비자에게 혜택을 제공하므로 호혜성

세 가지 전략이 동시에 탐지되면 각 카테고리 확률에 가중치와 강도 계수를 곱하고, 동시 탐지 보정 계수를 적용해 최종 점수를 계산합니다.

설명 포인트: 이 문구는 긴급성, 가격비교, 호혜성이 함께 있어서 점수가 중간 이상으로 나올 수 있습니다. 다만 권위·신뢰나 사회적 증명처럼 가중치가 높은 요소는 포함되지 않았기 때문에 매우 높은 점수까지는 가지 않을 수 있습니다.

10. 결과 점수 해석

핵심 해석: 점수는 “실제 구매 확률”이 아니라, 광고 문구 안에 소비심리를 자극하는 표현이 얼마나 많이, 얼마나 강하게 들어 있는지를 100점 기준으로 환산한 상대적 지표입니다.

점수 범위는 어떻게 봐야 하나?

구분범위설명
발표·사용자 해석 0~100점 기준 0에 가까울수록 자극 표현이 적고, 100에 가까울수록 여러 설득 전략이 강하게 결합된 것으로 설명하면 됩니다.
수식상 극단값 약 -135~135점까지 가능 방향성 계수와 강도 계수, 동시 탐지 보정이 들어가기 때문에 이론적으로는 0보다 작거나 100을 넘을 수 있습니다.
발표 권장 표현 100점 기준 환산값 논문·발표에서는 “0~100점 기준으로 해석하는 상대 지표”라고 말하고, 실제 서비스 표시에서는 0 미만은 0, 100 초과는 100으로 제한할 수 있다고 설명하는 것이 안전합니다.
짧은 답변: “사용자에게 보여줄 때는 0~100점 기준으로 해석합니다. 다만 계산식 자체는 강도와 보정 계수가 들어가므로 이론적으로 100을 넘거나 부정 방향 표현 때문에 0보다 낮아질 수 있어, 표시 단계에서는 0~100으로 제한하는 방식이 가장 직관적입니다.”
오해하기 쉬운 해석 올바른 해석
51.3점이면 구매 확률이 51.3%다.아님. 해당 문구가 모델 기준에서 중간 이상 수준의 자극 요소를 포함한다는 뜻입니다.
점수가 높으면 무조건 나쁜 광고다.아님. 설득 표현이 강하다는 뜻이지 허위·불법 광고라는 뜻은 아닙니다.
점수가 낮으면 광고 효과가 없다.아님. 이미지, 브랜드, 타깃팅, 제품력 등 텍스트 외 요소가 작용할 수 있습니다.

0~20점소비심리 자극 표현이 적거나 약한 편광고 효과가 없다는 뜻은 아님
20~50점일부 설득 전략이 포함된 보통 수준의 자극카테고리별 결과를 함께 봐야 함
50~70점여러 설득 전략이 동시에 나타나는 비교적 강한 자극예: 긴급성 + 가격비교 + 호혜성
70점 이상다수의 전략이 강하게 결합된 높은 자극 가능성허위 광고라는 뜻은 아니며 모니터링 우선순위로 볼 수 있음

11. 평가 지표 해석

Macro-F1을 대표 분류 지표(벤치마크)로 사용한 이유

Macro-F1은 7개 설득 전략 카테고리를 각각 얼마나 잘 찾았는지 계산한 뒤, 그 값을 단순 평균한 지표입니다. 이 연구에서는 카테고리별 데이터 개수가 균일하지 않기 때문에, 많이 등장하는 카테고리만 잘 맞혀도 높게 보일 수 있는 단순 정확도보다 Macro-F1이 더 적절한 비교 기준입니다.

※ 여기서 벤치마크는 외부 공개 벤치마크 데이터셋이라는 뜻이 아니라, 모델 성능을 비교할 때 기준으로 삼은 평가 지표라는 의미로 설명하면 안전합니다.

Precision

정밀도

모델이 “해당 카테고리다”라고 예측한 것 중 실제로 맞은 비율입니다.

Recall

재현율

실제로 해당 카테고리인 문구 중 모델이 놓치지 않고 찾아낸 비율입니다.

F1

균형 점수

정밀도와 재현율을 함께 반영한 값입니다. 둘 중 하나만 높아서는 F1이 높게 나오기 어렵습니다.

F1 = 2 × (정밀도 × 재현율) / (정밀도 + 재현율)
Macro-F1 = 7개 카테고리별 F1의 평균
주의: Macro-F1 0.826은 “정확도 82.6%”와 같은 뜻이 아닙니다. 7개 카테고리에 대해 정밀도와 재현율을 균형 있게 반영했을 때 평균 F1이 0.826이라는 의미입니다.
지표 값 의미 주의해서 말할 점
단일 모델 Macro-F10.8267개 카테고리별 F1을 동일 비중으로 평균발표 대표 분류 성능으로 사용 가능
앙상블 Macro-F10.8304개 모델 예측을 평균했을 때의 카테고리 분류 성능보조 성능으로 설명
방향성 F10.928표현 방향성을 맞힌 정도데이터 대부분이 긍정 방향이라 높게 나올 수 있음
강도 F1약 0.63~0.65강/보통/약 분류 성능주관적 판단이 들어가 상대적으로 어려운 과제
Pearson r0.838라벨 기반 기준 점수와 모델 예측 점수의 상관실제 클릭률·구매율과의 상관이 아님
R²0.702기준 점수의 변동을 예측 점수가 어느 정도 설명하는지 보는 보조 지표실제 구매 행동 설명력이 아니라 라벨 기반 점수 체계 안에서의 설명력
MAE5.80라벨 기반 기준 점수 대비 평균 오차100점 기준에서 평균 약 5.8점 차이

피어슨 상관계수 설명

피어슨 상관계수 r은 두 점수가 같은 방향으로 움직이는 정도를 보는 지표입니다.

r = 1에 가까움 → 두 점수가 거의 같은 방향으로 움직임 r = 0에 가까움 → 두 점수 사이의 선형 관계가 약함 r = -1에 가까움 → 반대 방향으로 움직임
발표 답변 문장: “피어슨 상관계수는 실제 구매율과의 상관이 아니라, 라벨과 점수식으로 만든 기준 점수와 모델 예측 점수가 얼마나 같은 흐름으로 움직이는지를 본 지표입니다. 0.838이므로 모델이 점수 체계의 경향성을 비교적 잘 재현했다고 해석했습니다.”

12. 기술 질문 대비 답변

Q1. 모델이 가중치까지 학습한 건가요?
아닙니다. 카테고리 점수 가중치 Wᵢ는 모델이 직접 학습한 값이 아니라, 선행연구를 참고해 사전에 설정한 점수 계산용 가중치입니다. 모델은 광고 문구에서 카테고리, 방향성, 강도를 예측하도록 학습했고, 그 예측값에 가중치를 곱해 최종 점수를 계산했습니다.
Q2. 왜 멀티라벨 분류인가요?
하나의 광고 문구 안에 여러 설득 전략이 동시에 들어갈 수 있기 때문입니다. 예를 들어 “오늘만 50% 할인 무료배송”은 긴급성, 가격비교, 호혜성이 동시에 포함됩니다.
Q3. Macro-F1 0.826은 정확도 82.6%라는 뜻인가요?
아닙니다. Macro-F1은 정확도가 아니라, 7개 카테고리 각각의 F1 점수를 평균한 분류 성능 지표입니다. F1은 정밀도와 재현율을 함께 보는 값이기 때문에, 모델이 특정 카테고리를 과하게 예측하거나 너무 놓치는 경우 모두 점수가 낮아집니다. 이 연구에서는 카테고리별 데이터 수가 다르기 때문에 Macro-F1을 대표 분류 지표로 사용했습니다. 다만 외부 공개 벤치마크를 사용했다는 뜻이 아니라, 자체 테스트셋에서 모델 성능을 비교하는 기준 지표로 사용했다는 의미입니다.
Q4. 강도는 어떤 기준으로 나온 건가요?
강도는 라벨링 단계에서 사람이 정한 약·보통·강 기준을 모델이 학습한 결과입니다. 표현이 더 구체적이고 직접적으로 구매를 유도할수록 강하게 분류됩니다.
Q5. Pearson r=0.838은 정확도를 뜻하나요?
정확도와는 다릅니다. Pearson r은 기준 점수와 예측 점수가 같은 방향으로 움직이는 정도를 보는 상관 지표입니다. 실제 소비자 클릭률이나 구매율과의 상관은 아닙니다.
Q6. AI 라벨링을 썼다면 데이터가 편향될 수 있지 않나요?
그 가능성이 있습니다. 그래서 초기에는 사람이 직접 라벨링하면서 기준을 정리했고, 그 기준으로 AI 라벨링을 확장했습니다. 다만 모든 데이터가 독립적인 인간 평가자에 의해 검증된 것은 아니므로, 향후 인간 gold set 검증이 필요합니다.
Q7. 앙상블 모델을 왜 사용했나요?
여러 모델의 예측을 평균하면 한 모델의 우연한 오차를 줄일 수 있기 때문입니다. 단일 모델은 Macro-F1 0.826, 4개 모델 앙상블은 0.830으로 소폭 개선되었습니다. 다만 개선 폭이 크지는 않기 때문에 대표 설명은 단일 모델 중심으로 하고, 앙상블은 안정성을 높인 보조 실험으로 설명하는 것이 적절합니다.
Q8. 이 점수는 실제 소비자가 충동구매할 확률인가요?
아닙니다. 이 점수는 실제 구매 확률이 아니라 광고 텍스트 안의 설득 전략 자극 정도를 상대적으로 보여주는 합성지표입니다. 실제 클릭률, 구매 전환율, 소비자 실험 데이터를 넣어 검증하면 이후 더 실증적인 점수로 발전시킬 수 있습니다.
Q9. 사기성 광고 탐지에도 바로 사용할 수 있나요?
단독으로 “사기 광고다”라고 판정하는 모델은 아닙니다. 다만 긴급성, 희소성, 권위·신뢰 표현이 과도하게 결합되거나 “공식 인증”, “오늘 마감”, “품절임박” 같은 표현이 반복되는 광고를 우선 검토 대상으로 걸러내는 보조 신호로 활용할 수 있습니다. 실제 사기 탐지로 확장하려면 광고주 정보, URL, 랜딩페이지, 결제 방식, 신고 이력, 이미지·영상 정보와 함께 판단해야 합니다.
Q10. 점수 범위는 정확히 0~100점인가요?
발표와 프로그램 화면에서는 0~100점 기준의 상대 지표로 해석하면 됩니다. 다만 수식 자체는 확률, 방향성, 강도, 동시 탐지 보정 계수를 곱하는 구조라서 극단적인 경우 100을 넘거나, 부정 방향 표현이 강하면 0보다 작아질 수도 있습니다. 그래서 사용자에게 보여주는 단계에서는 0 미만은 0점, 100 초과는 100점으로 제한하거나, “100점 기준 환산값”이라고 설명하는 것이 안전합니다.

13. 발표 내용 기준 추가 기술 보강 포인트

발표 시간을 고려하면 아래 내용을 모두 길게 넣을 필요는 없습니다. 다만 심사자가 기술적으로 질문하기 쉬운 부분이므로, 발표 중 한 문장으로 보강하거나 질의응답에서 바로 설명할 수 있게 준비하는 것이 좋습니다.

발표 위치 부족해 보일 수 있는 기술 설명 보강·답변 방향
데이터 수집 Meta Ads Library에서 수집했다는 설명은 있지만, 어떤 데이터를 제외했는지 짧게 보강하면 좋음 중복 문구, 비어 있는 문구, 분석에 적합하지 않은 비텍스트성 문구를 제거해 최종 6,149건을 만들었다고 설명
라벨링 사람 라벨링과 AI 라벨링의 관계가 모호하게 들릴 수 있음 초기 사람이 기준을 잡고 중복 라벨링으로 기준을 맞춘 뒤, 같은 기준을 이용해 AI 라벨링을 확장했다고 설명
학습 데이터 분할 검증셋과 테스트셋을 왜 나눴는지 설명이 부족할 수 있음 검증셋은 threshold와 설정 조정에 사용하고, 테스트셋은 최종 성능 확인에만 사용했다고 설명
모델 학습 모델이 무엇을 학습했고 무엇은 계산식인지 헷갈릴 수 있음 모델은 카테고리·방향성·강도를 예측하도록 학습했고, 가중치와 보정 계수는 점수 계산식에 적용한 설계값이라고 구분
Loss와 threshold Macro-F1은 말하지만 학습에서 오차를 어떻게 줄였는지 설명이 짧음 카테고리는 멀티라벨 BCE/focal loss, 방향성·강도는 cross entropy로 학습했고, 카테고리별 threshold는 검증셋에서 조정했다고 설명
점수의 정답값 “정답 점수”가 실제 소비자가 평가한 점수인지 오해될 수 있음 정답 점수는 소비자 행동 데이터가 아니라, 라벨과 점수식을 이용해 만든 기준 점수라고 분명히 말하기
점수 계산 카테고리 확률과 탐지 여부가 어떻게 점수에 들어가는지 질문받을 수 있음 threshold를 넘은 양성 카테고리를 중심으로, 모델 확률에 가중치·방향성·강도·동시탐지 보정을 곱해 계산한다고 설명
가중치·S(n) 가중치와 동시 탐지 보정 계수가 “학습된 값”처럼 들릴 수 있음 선행연구와 설득 이론을 바탕으로 둔 초기 설계값이며, 실제 클릭률·구매율 데이터가 생기면 보정할 수 있다고 답변
성능 평가 Macro-F1, Pearson r, R², MAE가 각각 무엇을 보는지 한꺼번에 나오면 헷갈릴 수 있음 Macro-F1은 카테고리 분류, Pearson r/R²/MAE는 라벨 기반 점수 예측을 보는 지표이며 실제 구매율 검증은 아니라고 구분
앙상블 앙상블이 핵심 성능 향상처럼 보일 수 있음 서로 다른 설정의 모델 예측을 평균해 안정성을 높인 보조 실험이며, 개선 폭은 0.826→0.830으로 크지 않다고 설명
프로그램 구현 웹페이지가 단순 데모인지 실제 운영 시스템인지 질문받을 수 있음 현재는 입력 문구를 분석해 점수와 카테고리별 기여도를 보여주는 프로토타입이며, 실시간 광고 수집·이미지/영상 분석은 향후 과제라고 설명
사기성 광고 활용 “사기 탐지 가능”이라고만 말하면 실제 사기 여부를 판정한 것처럼 들릴 수 있음 사기 판정 모델이 아니라, 과도한 심리 자극 문구를 찾아내는 위험 신호 탐지·모니터링 보조 도구로 설명

발표에 바로 넣기 좋은 한 문장 보강

  1. “검증셋은 기준값 조정에 사용했고, 테스트셋은 최종 성능 확인에만 사용했습니다.”
  2. “모델이 가중치를 학습한 것이 아니라, 모델은 카테고리·방향성·강도를 예측하고 점수식에서 가중치를 적용했습니다.”
  3. “정답 점수는 실제 구매율이 아니라 라벨과 점수식으로 만든 기준 점수입니다.”
  4. “Macro-F1은 정확도가 아니라 7개 카테고리별 F1을 동일 비중으로 평균한 지표입니다.”
  5. “현재 점수는 절대적인 구매 확률이 아니라 광고 문구 간 자극 정도를 비교하기 위한 상대 지표입니다.”
가장 조심할 표현: “실제 소비자가 구매할 가능성을 예측했다”라고 말하면 과장으로 들릴 수 있습니다. “텍스트에 포함된 설득 전략의 자극 정도를 라벨 기반 점수 체계 안에서 예측했다”라고 말하는 것이 안전합니다.

사기성 광고 탐지 활용은 이렇게 보강하기

발표자료에서는 “사기 광고를 판별한다”보다 “사기성 광고 모니터링의 보조 지표로 활용할 수 있다”고 표현하는 것이 안전합니다. 본 모델은 텍스트 안의 심리 자극 전략을 찾는 모델이므로, 허위 여부 자체를 증명하는 것은 아니기 때문입니다.

탐지 가능한 위험 신호예시 표현해석
과도한 긴급성오늘 마감, 3시간 후 종료, 지금 안 사면 손해충분한 판단 시간을 줄이는 압박 표현
과도한 희소성품절임박, 한정 수량, 선착순 마감수량 제한을 강조해 빠른 결정을 유도
권위·신뢰 표현공식 인증, 전문가 추천, 기관 승인실제 인증 여부 확인이 필요한 표현
복합 자극공식 인증 + 오늘 마감 + 90% 할인여러 설득 전략이 동시에 쓰여 고위험 후보로 검토 가능
발표용 문장: “이 모델이 사기 여부를 직접 판정하는 것은 아니지만, 긴급성·희소성·권위·신뢰 표현처럼 사기성 광고에서 자주 함께 나타날 수 있는 심리 자극 문구를 탐지해 고위험 광고를 우선 검토하는 보조 지표로 활용할 수 있습니다.”
질문 대응: “사기 탐지로 쓰려면 이 모델만으로는 부족하고, 향후 광고주 정보, URL, 랜딩페이지, 신고 이력, 이미지·영상 정보와 결합해야 합니다.”

14. 발표용 짧은 설명 문장

데이터는 Meta Ads Library에서 수집한 한국어 광고 텍스트를 정제해 만들었고, 각 문구에 7개 설득 전략, 방향성, 강도 라벨을 부여했습니다. 이후 KLUE-RoBERTa-large가 이 라벨을 학습해 광고 문구의 카테고리·방향성·강도를 예측하도록 했습니다. 최종 점수는 모델 예측값에 문헌 기반 초기 가중치와 동시 탐지 보정 계수를 적용해 100점 기준으로 환산한 값입니다. 따라서 이 점수는 실제 구매 확률이 아니라 광고 문구의 소비심리 자극 가능성을 비교하기 위한 상대적 지표입니다.
