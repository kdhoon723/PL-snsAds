## 사이클 기록

### Cycle 1: Baseline (klue/roberta-base, 디폴트)

**가설**: KLUE-RoBERTa base + 자동 pos_weight + 기본 하이퍼파라미터 = 베이스라인 확보

**설정**:
- model: `klue/roberta-base`
- max_length: 128, batch: 16, lr: 3e-5, dropout: 0.3
- pos_weight: 자동 (양성 빈도 역수), scale=1.0
- epochs: 10, patience: 3

**결과**:
| 메트릭 | 값 |
|---|---|
| Test Macro F1 | **0.7546** |
| Test Micro F1 | 0.7785 |
| 강도 MAE | 0.0759 |
| 학습 시간 | ~90초 |

카테고리별 F1:
- 호혜성 0.840 · 희소성 0.817 · 가격비교 0.805 · 사회적_증명 0.795
- 권위_신뢰 0.758 · 긴급성 0.703 · **사회적_정체성 0.564** ⚠️

**해석**:
- 첫 사이클부터 Macro F1 0.75 = 매우 양호
- 강도 MAE 0.076 = 가중치 점수 산출 신뢰 가능 (0~0.84 범위)
- 사회적_정체성만 명확히 약함 (P 0.55 / R 0.58, 양성 7.8%)
- RTX 5090에서 9초/epoch = 빠른 실험 가능

**기록**: `runs/cycle1_baseline/`

### Cycle 2: pos_weight × 1.5 (소수 카테고리 강화)

**가설**: 자동 pos_weight를 1.5배 키우면 약한 카테고리(정체성) F1 ↑ + 전체 Macro F1 ↑

**설정**: Cycle 1 + `--pos-weight-scale 1.5`

**결과**:
| 메트릭 | Cycle 1 | Cycle 2 | Δ |
|---|---|---|---|
| Test Macro F1 | 0.7546 | **0.7457** | -0.009 |
| 강도 MAE | 0.0759 | 0.0799 | +0.004 |
| 사회적_정체성 F1 | 0.564 | **0.548** | -0.016 |
| 사회적_증명 F1 | 0.795 | 0.806 | +0.011 |
| 권위_신뢰 F1 | 0.758 | 0.773 | +0.015 |

**해석**:
- ❌ **가설 기각**. pos_weight 1.5x는 오히려 약한 카테고리(정체성) 더 나빠짐.
- 일부 카테고리(증명, 권위) 미세 개선 → 전체 균형 깨짐
- precision 떨어지고 recall ↑ (양성 더 잡으려다 false positive 늘어남)
- 자동 pos_weight가 이미 잘 보정되어 있음

**다음 가설**: 1.5가 안 되면 2.0/3.0도 안 될 가능성. 다른 방향(Focal Loss, oversampling, 모델 변경)으로.

**기록**: `runs/cycle2_posweight1.5/`

### Cycle 3: roberta-large

**가설**: 더 큰 모델(roberta-large, ~340M)은 약한 카테고리·복잡한 의미 더 잘 잡음

**설정**: model=`klue/roberta-large`, batch=8, lr=2e-5

**결과**:
| 메트릭 | Cycle 1 | Cycle 3 | Δ |
|---|---|---|---|
| Test Macro F1 | 0.7546 | 0.7509 | -0.004 |
| **강도 MAE** | 0.0759 | **0.0616** | **-0.014 ✨** |
| 사회적_정체성 F1 | 0.564 | **0.597** | +0.033 ✨ |
| 권위_신뢰 F1 | 0.758 | 0.758 | 0 |
| 가격비교 F1 | 0.805 | 0.810 | +0.005 |
| 긴급성 F1 | 0.703 | 0.670 | -0.033 |
| 호혜성 F1 | 0.840 | 0.814 | -0.026 |

→ Early stopping (epoch 6에서 patience 소진)

**해석**:
- ✅ **강도 MAE 큰 개선** (-18% relative). 학술 점수 산출에는 large가 명확히 우위
- ✅ **사회적_정체성 개선** (가장 약했던 카테고리). large 모델이 적은 양성도 잘 학습
- ⚠️ 일부 강한 카테고리(긴급성, 호혜성) 약간 하락 — overfitting 빠름
- ⚠️ Early stopping 3 epoch만에 → patience 5 / 더 낮은 lr로 더 학습 가능성

**다음 가설**: roberta-large + patience 5 + lr 1e-5 + epochs 15로 충분 학습하면 Macro F1 0.77+ 가능?

**기록**: `runs/cycle3_roberta_large/`

### Cycle 4: 학술 가중치 반영 (klue/roberta-base + academic-weighted)

**가설**: BCE loss에 학술 가중치(권위 0.221 ... 가격 0.091)를 곱해 학습 → 강도 MAE 더 좋아짐 + 권위 F1 ↑

**설정**: Cycle 1 + `--academic-weighted` (학술 가중치 평균 1.0으로 정규화 후 BCE weight 곱)

**결과**:
| 메트릭 | Cycle 1 | Cycle 4 | Δ |
|---|---|---|---|
| Test Macro F1 | 0.7546 | 0.7537 | -0.001 |
| 강도 MAE | 0.0759 | 0.0774 | +0.002 ❌ |
| 사회적_정체성 F1 | 0.564 | **0.585** | +0.021 ✨ |
| 권위_신뢰 F1 | 0.758 | **0.767** | +0.009 ✨ |
| 호혜성 F1 | 0.840 | 0.809 | -0.031 |

**해석**:
- ❌ **강도 MAE 가설 기각**. 학술 가중치 학습 반영해도 MAE 개선 없음 (오히려 약간 ↑)
- ✅ **권위 F1 가설 부분 채택**. 학술 중요 카테고리(권위·정체성) 약간 개선
- ⚠️ 반대급부: 학술 가중치 낮은 호혜성(0.151) 하락
- **균등 학습 후 사후 가중치**가 가장 합리적 (현재 기본 설계 유효)

**다음 가설**: 학술 가중치는 추론 단계에만 쓰고 학습은 균등 유지. 다른 방향(긴 컨텍스트, 다른 모델)으로.

**기록**: `runs/cycle4_academic_weighted/`

| 사회적_정체성 F1 | 0.564 | 0.597 | **0.598** | +0.034 |
| 희소성 F1 | 0.817 | 0.812 | **0.841** | +0.024 |
| 사회적_증명 F1 | 0.795 | 0.795 | **0.810** | +0.015 |

| 가격비교 F1 | 0.805 | 0.810 | 0.795 | -0.010 |

**해석**:
- ✅ **가설 채택**. lr↓ + patience↑로 large 모델 충분 학습 → Macro F1 + MAE 모두 새 최고
- 약한 카테고리(정체성) + 희소성 등 일반 카테고리 모두 개선
- 일부 강한 카테고리(가격비교, 호혜성) 미세 하락 — 큰 모델이 어려운 구분에 자원 할당

### Cycle 9: Focal γ=1.0 (덜 강한 focal)

**가설**: γ=2.0이 너무 공격적일 수도. γ=1.0이면 권위 같은 미묘한 카테고리도 살리면서 F1 유지

| **호혜성 F1** | 0.861 | **0.867** | +0.006 ✨ |
| **긴급성 F1** | 0.701 | **0.743** | +0.042 ✨✨ |
| **권위 F1** | 0.764 | **0.786** | +0.022 |

- 모든 약한 카테고리(정체성·긴급성·권위) 동시 개선 — Focal Loss의 본질적 효과
- 강한 카테고리(가격·증명) 약간 하락 — Focal이 어려운 것 강조하니 쉬운 것 약해짐 자연

**기록**: `runs/cycle9_focal_gamma1/`

- ✅ **MAE 신기록** (0.0574). 강한 카테고리 정확도 ↑ + 정확도 가중치 평균 효과

6. **dropout**: 0.1 최적 (0.0 overfit / 0.3+ underfit, 비선형)
7. **앙상블**: 3 모델 일관(γ=1.0 변형) 가장 효과적. 5+ 모델은 약화
8. **seed variation < 설정 variation**: 같은 설정 다른 seed 평균은 미약
9. **학술 가중치 학습 반영 불필요**: 사후 강도 점수 산출에만 사용
10. **pos_weight 자동 OK**: scale 1.5x는 오히려 약화

# 🔬 Multitask 학습 (Cycle 38~) — 진행 예정

## 배경
PDF (`모델학습/가중치 계산.pdf`) 설계 도입. 카테고리(multi-label sigmoid) + 방향성(softmax) + 강도(softmax) 동시 학습으로 더 풍부한 점수 산출. Phase C에서 6,400+건 방향성·강도 라벨링 완료 후 학습.

## 학습 데이터 (예상)
- 통합데이터셋 v2: 카테고리 7 + 카테고리별 방향성(3) + 카테고리별 강도(3) = 7 + 7×3 + 7×3 = 49 라벨/광고
- 음성 카테고리는 방향성·강도 mask (학습 시 loss에 미포함)

## 모델 구조
```
BERT 인코더 (shared)
 ├─ category_head: Linear(hidden, 7) → sigmoid → BCE
 ├─ polarity_head: Linear(hidden, 7×3) → reshape (B, 7, 3) → softmax → CE (masked)
 └─ intensity_head: Linear(hidden, 7×3) → reshape (B, 7, 3) → softmax → CE (masked)
```

## Cycle 계획 (10~13 cycle 예정)

### Cycle 38: Multitask baseline (PDF 권장)
- Cycle 19 설정 + multitask 0.6/0.2/0.2
- klue/roberta-large, max_len 256, batch 8, lr 1e-5, focal γ=1.0, dropout 0.1
- 검증: 카테고리 F1 (cycle 19와 비교), polarity F1, intensity F1, 강도 점수 MAE (PDF 공식)

### Cycle 39~41: Loss weighting
- 39: 0.5/0.25/0.25 (균등 가까이)
- 40: 0.4/0.3/0.3 (보조 task 비중 ↑)
- 41: 0.7/0.15/0.15 (카테고리 비중 ↑)

### Cycle 42: Uncertainty weighting (Kendall et al. 2018)
- 자동 task balance — log variance 학습으로 unstable task 자동 다운웨이트

### Cycle 43: GradNorm (Chen et al. 2018)
- gradient magnitude 정규화 — 적응적 task balance

### Cycle 44: Polarity focal (불균형 대응)
- 38 + polarity CE → focal CE γ=2.0 (부정·중립 적으므로)

### Cycle 45: Intensity weighted CE
- 38 + intensity 클래스 가중치 (강/보통/약 불균형 보정)

### Cycle 46: 2-stage training
- Stage 1: 카테고리만 학습 (3 epoch)
- Stage 2: 모든 head joint fine-tune (10 epoch)

### Cycle 47: Polarity oversampling
- 부정·중립 케이스 oversampling (5~10배) — IRR 검증된 표본 부족 대응

### Cycle 48: 강도 점수 MAE 직접 최적화
- BCE/CE 외에 강도 점수 MAE 손실 추가 (auxiliary)

### Cycle 49~50: Multitask ensemble
- Best 3 cycle 앙상블 (Cycle 23 패턴 재현)

## 검증 metric
1. **카테고리 Macro F1** (cycle 23 0.7871과 비교)
2. **Polarity F1** (카테고리별 + 전체, weighted by 양성 빈도)
3. **Intensity F1** (카테고리별 + 전체)
4. **강도 점수 MAE** (PDF 공식 `Σ w × ĉ × p × t × synergy`)
5. **단순 모델 v1 vs 풍부 v2 비교 분석**

## 가설 (사전)
- H1: Multitask가 카테고리 단독보다 약간 ↓ (보조 task로 인한 capacity 분산), 단 강도 점수 MAE는 개선
- H2: 손실 가중치 0.6/0.2/0.2이 baseline. uncertainty weighting (cycle 42)이 더 robust
- H3: Polarity focal (cycle 44)이 부정·중립 F1 ↑
- H4: 2-stage (cycle 46)이 joint보다 약간 ↑ — 카테고리 학습 안정화 후 보조 task
- H5: 앙상블 (cycle 49~50)이 단일 best보다 0.005~0.01 ↑ (cycle 23 패턴)
