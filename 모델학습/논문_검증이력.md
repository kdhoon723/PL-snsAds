## 5. 결론 스탠스 (상세 = 논문_결론.md)
- 점수는 **합성지표(composite index)** + 가중치는 **a priori 설계 파라미터**(실측 r 직접 정규화 아님). OECD/JRC(2008) 근거.
- 한계 정직 고지: 일부 카테고리 메타분석 부재 / 카테고리 간 공분산 미반영 / 한국 표본 미포함.
- LLM 라벨링: ablation(LLM-only F1 0.77 ≈ 통합 0.78)으로 "학습에 충분"은 단언, "인간 품질 동일 입증"은 아님(테스트셋도 LLM 라벨 → 순환성). 향후 인간 gold 검증.

## 6. 알아둘 결정/주의
- **모델**: KoBERT 아님 **KLUE-RoBERTa-large** 사용. KoBERT는 설계 단계서 제외(위키·뉴스 격식체·구버전). 실험 비교는 KLUE>base>KcBERT>KoELECTRA(EXPERIMENTS.md). **KF-DeBERTa(2023)는 미시도** — 더 밀려면 다음 후보(단 소규모 데이터라 체감 향상 작을 듯).
- **순환성 주의**: 점수 회귀 r=0.838은 예측 vs 라벨기반 정답점수라 부분 동어반복. ablation도 마찬가지 → "구조 기여도"로만 해석(점수식_학술근거.md §4.1).
- 권위 r=.44(Wilson&Sherrell 실측 ~.40)·증명 r=.317(미검증)은 a priori라 방어되나 원문 대조 시 차이 있음.
