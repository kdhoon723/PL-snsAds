4. 예상 질문과 답변

Q1. 이 점수가 실제 구매 가능성이나 클릭률을 의미하나요?
아닙니다. 본 연구의 점수는 실제 클릭률이나 구매 전환율을 직접 예측한 값이 아니라, 광고 문구 안에 포함된 설득 전략의 자극 가능성을 상대적으로 수치화한 합성지표입니다. 따라서 절대적인 구매 예측값보다는 광고 문구 간 비교 지표로 해석하는 것이 적절합니다. 향후에는 클릭률이나 구매 전환율 데이터를 활용해 가중치를 보정할 계획입니다.
Q2. Pearson r=0.838이면 소비자 반응과 잘 맞는다는 뜻인가요?
Pearson r=0.838은 실제 소비자 행동 데이터와의 상관이 아니라, 테스트셋 라벨과 점수식으로 산출한 기준 점수와 모델 예측 점수 간의 상관입니다. 즉, 모델이 저희가 정의한 라벨링 및 점수 체계를 얼마나 잘 재현하는지를 보여주는 지표입니다. 실제 소비자 반응과의 검증은 향후 과제입니다.
Q3. AI로 라벨링했다면 정답 데이터가 믿을 만한가요?
초기에는 사람이 직접 라벨링하면서 카테고리 기준과 경계 사례를 정리했고, 그 기준을 바탕으로 AI 라벨링을 확장했습니다. 다만 모든 데이터가 독립적인 인간 평가자에 의해 검증된 것은 아니기 때문에, 라벨 품질과 외적 타당도는 한계로 인정합니다. 후속 연구에서는 별도의 인간 gold set을 구축해 검증할 계획입니다.
Q4. 가중치는 실제 효과크기인가요?
가중치는 실제 한국 소비자 행동 데이터로 최적화한 값은 아닙니다. 선행연구에서 제시된 설득 전략의 영향 방향과 상대적 중요도를 참고해 설정한 초기 가중치입니다. 따라서 현재 점수는 절대적 판단 기준이 아니라 문헌 기반 초기 합성지표로 보는 것이 맞습니다. 실제 광고 클릭률이나 구매 데이터가 확보되면 가중치를 재보정할 수 있습니다.
Q5. 멀티태스크 모델이 실제로 성능을 올렸나요?
카테고리 분류 성능만 보면 데이터 보강 효과가 가장 컸습니다. 멀티태스크 구조의 핵심 목적은 단순 F1 향상보다는 카테고리뿐 아니라 방향성과 표현 강도를 함께 예측해 최종 점수 계산에 필요한 정보를 제공하는 데 있습니다.
Q6. F1 0.787, 0.826, 0.830 중 어떤 게 맞나요?
0.787은 초기 v1 모델 성능이고, 0.826은 최종 단일 KLUE-RoBERTa-large 멀티태스크 모델의 테스트 Macro-F1입니다. 0.830은 4개 모델 앙상블 기준 성능입니다. 발표에서는 단일 모델 기준 0.826을 대표 성능으로 보고했고, 앙상블에서는 0.830까지 확인했습니다.
Q7. 사기성 광고 탐지가 가능하다고 했는데, 진짜 사기 여부도 판단하나요?
현재 모델은 사기 여부를 직접 판별하는 모델은 아닙니다. 다만 긴급성, 희소성, 허위 권위 표현처럼 사기성 광고에서도 자주 쓰이는 심리 자극 패턴을 탐지할 수 있기 때문에, 향후 사기 광고 탐지 시스템의 보조 특징으로 활용할 수 있습니다. 실제 사기 판별에는 URL, 광고주 정보, 신고 이력, 이미지 검증 등이 함께 필요합니다.

6. 발표자가 외워두면 좋은 방어 문장

본 연구의 점수는 실제 구매율을 예측하는 절대 지표가 아니라, 광고 텍스트 안의 설득 전략을 문헌 기반 가중치와 모델 예측값으로 계산한 상대적 합성지표입니다. 따라서 현재 단계에서는 광고 문구 간 비교와 자극 요소 분석에 의미가 있고, 실제 소비자 행동 데이터 기반 보정은 향후 과제입니다.
